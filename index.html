VAYUMESH | SYSTEM PIPELINE (SIH 26158)

From a Single Drone Video to Trusted 3D Intelligence

End-to-end 8-stage automated photogrammetric architecture converting raw UAV flight captures into metric-accurate, georeferenced 3D digital twins in under 15 minutes.

STAGE 01

Input: Drone Video + Telemetry

Single-pass UAV video ingest (MP4) synchronized with GNSS/GPS coordinates, high-frequency IMU attitude orientation, and RTK/PPK centimetre-grade positioning stream.

INPUT: MP4 + GNSS + IMU + RTK/PPK
STAGE 02

Preprocessing: Keyframe Selection

Intelligent automated frame extraction, Laplacian blur rejection, optical flow overlap validation, and texture entropy ranking to select optimal reconstruction baselines.

OUTPUT: Optimized Keyframes
STAGE 03

Dynamic Object Masking

Segment Anything Model 2 (SAM2) video segmentation combined with YOLO detection to identify and mask moving people, tourists, and vehicles, isolating static heritage surfaces.

OUTPUT: Clean Reconstruction Frames
STAGE 04

3D Reconstruction: VGGT + COLMAP

Visual Geometry Grounded Transformer (CVPR 2025) estimates dense monocular depth and camera poses across sparse viewpoints; COLMAP refines geometric bundle adjustment.

OUTPUT: Camera Poses + Point Cloud
STAGE 05

Sensor Fusion & Georeferencing

GTSAM factor-graph non-linear optimization fusing GNSS, IMU, and RTK priors to recover absolute metric scale (1 unit = 1m) without manual Ground Control Points (Zero-GCP).

OUTPUT: Metric 3D Structure (m)
STAGE 06

Dense 3D Model: Gaussian Splatting

Converts sparse structure into dense 3D representation via DroneSplat (3DGS) and HiDeGS adaptive densification, coupled with Poisson reconstruction for watertight solid mesh generation.

OUTPUT: Detailed 3D Solid Model
STAGE 07

Confidence Engine Reliability

Quantifies reconstruction reliability per surface triangle using reprojection error, multi-view depth consistency, photometric residuals, and point density.

OUTPUT: Confidence Score + Heatmap
STAGE 08

Trusted 3D Intelligence Output

Actionable defence outputs: watertight metric 3D model, Green/Yellow/Red confidence map, georeferenced orthomosaic (GeoTIFF/LAS/OBJ/GLB/KMZ), and terrain elevation data.

OUTPUT: Mission-Ready Intelligence
DEFENCE FEASIBILITY & TECHNICAL STACK

Open-Source Proven Technology Stack

Modular, offline-ready software-first architecture designed for disconnected, challenging operational military environments.

CORE RECONSTRUCTION ENGINE

VGGT / VGGT Omega + COLMAP

Feed-forward visual geometry transformer foundation model handling sparse, low-overlap (10–30%) single-pass drone aerial video where classical photogrammetry collapses.

UAV-DOMAIN FINE-TUNING

UAFF3D · PyTorch 2.3.1 + CUDA 12.1

Fine-tuned on UAVFF3D (170k real + 370k synthetic aerial images with LiDAR ground truth), cutting Ray Error by 84.2%, Pose ATE by 76.0%, and Chamfer Distance by 41.1%.

SENSOR FUSION & SCALE

GTSAM · ORB-SLAM3 · RTKLIB

Visual-inertial SLAM fusing GPS/IMU with visual features to deliver metric-scale 6-DoF poses at 2–10 cm accuracy, eliminating ground control point dependencies.

DENSE 3D MODELING

DroneSplat (3DGS) · HiDeGS · Poisson

Robust 3D Gaussian Splatting and screened Poisson surface reconstruction yielding watertight CAD solids, dense point clouds, and confidence-colored mesh representations.

DYNAMIC FILTERING

SAM2 Segmentation + YOLOv10

Sub-frame masking of transient pedestrians, tourist crowds, vehicles, and moving vegetation to preserve structural architectural truth.

DEPLOYMENT & SECURITY

Docker + Ubuntu · 100% Air-Gapped

Zero network calls, zero cloud dependency. Sensitive reconnaissance data never leaves the military edge device, meeting strict Ministry of Defence (MoD) security protocols.
